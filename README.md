# 🎮 Termux 마인크래프트 베드락 전용 서버 (BDS) 원클릭 자동 설치 & 복구기

안드로이드 스마트폰의 **Termux** 환경에서 마인크래프트 공식 BDS(Bedrock Dedicated Server)를 자동으로 구축하고, 누구나 쉽게 관리할 수 있는 한글 대시보드(`mc`)를 설치해 주는 원클릭 스크립트입니다.

---

## 🚀 폰 초기화 후 한 줄로 복구 / 설치하기

스마트폰을 공장초기화했거나 새로 설치할 때, **Termux 앱을 켜고 아래 한 줄 명령어만 복사해서 붙여넣고 엔터**를 치시면 됩니다:

```bash
curl -sL https://raw.githubusercontent.com/danielkj08/termux-mc-bds/main/install.sh | bash
```

설치가 완료되면(약 3~5분 소요), Termux에서 **`mc`** 만 입력하시면 한글 관리자 메뉴가 바로 실행됩니다!

---

## 🌟 주요 기능

* **Ubuntu + Box64 자동 세팅:** ARM64 모바일 환경에서 x86_64 공식 BDS 바이너리 완벽 호환 구동
* **초간편 한글 대시보드 (`mc`):** 번호만 눌러서 모든 제어 가능
  * 서버 켜기 / 끄기 / 재시작
  * **👑 OP 권한 관리:** 현재 접속 중인 플레이어 및 최근 접속 기록 목록에서 번호로 바로 선택하여 OP 부여/회수 (`permissions.json` 자동 연동으로 재접속 시에도 영구 유지)
  * **⚡ 물약 버프:** 신속, 성급함, 힘, 재생, 저항, 야간투시 등 12가지 버프를 플레이어 번호 선택 또는 전체(`@a`)로 원클릭 부여
  * **⚙️ 실시간 게임 설정:** 난이도(평화로움/쉬움/보통/어려움), 기본 게임모드(서바이벌/크리에이티브/모험), Xbox 정품인증 여부, 치트/도전과제 토글
  * **💀 하드코어 모드 완벽 지원:** 목숨 1개, 사망 시 관전 모드 강제 전환, 하드코어 전용 하트 UI (`level.dat` NBT 자동 주입)
  * **🌍 새 월드 생성 마법사 (`reset_world.sh`):** 월드 이름, 커스텀 시드(Seed), 난이도, 게임모드, 하드코어, 도전과제 여부를 직접 선택하여 완전히 새로운 맵 생성 (기존 월드는 타임스탬프 압축 파일로 자동 안전 백업)
  * **⌨️ 콘솔 명령어 한 줄 실행:** `time set day`, `weather clear` 등 직접 실행
  * **📊 실시간 부하 모니터링:** 마크 프로세스 CPU/RAM 점유율, 폰 전체 메모리 상태
  * **💾 백업 & 복구 (Restore):** 날짜별 백업 목록에서 번호 선택으로 원클릭 롤백
  * **📦 백업 파일 내보내기:** 폰 '다운로드' 폴더로 복사하거나 간이 웹 서버(`http://IP:8080`)로 PC에서 다운로드
* **절전 방지 자동 적용:** 화면이 꺼져도 서버가 중단되지 않도록 `termux-wake-lock` 기본 적용
