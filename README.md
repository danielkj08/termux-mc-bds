# 🎮 Termux 마인크래프트 베드락 전용 서버 (BDS) 원클릭 자동 설치 & 복구기

안드로이드 스마트폰의 **Termux** 환경에서 마인크래프트 공식 BDS(Bedrock Dedicated Server)를 자동으로 구축하고, 누구나 쉽게 관리할 수 있는 한글 대시보드(`mc`)를 설치해 주는 원클릭 스크립트입니다.

---

## 🚀 폰 초기화 후 한 줄로 복구 / 설치하기

스마트폰을 공장초기화했거나 새로 설치할 때, **Termux 앱을 켜고 아래 한 줄 명령어만 복사해서 붙여넣고 엔터**를 치시면 됩니다:

```bash
curl -sL https://raw.githubusercontent.com/danielkj08/termux-mc-bds/main/install.sh | bash
```

설치가 완료되면(약 3~5분 소요), Termux에서 **`mc`** 만 입력하시면 한글 관리자 메뉴가 바로 실행됩니다!

---

## 🌟 주요 기능
* **Ubuntu + Box64 자동 세팅:** ARM64 모바일 환경에서 x86_64 공식 BDS 바이너리 완벽 호환 구동
* **초간편 한글 대시보드 (`mc`):** 번호만 눌러서 모든 제어 가능
  * 서버 켜기 / 끄기 / 재시작
  * 접속 중인 플레이어 번호 선택으로 관리자(OP) 권한 부여
  * 12가지 물약 버프(신속, 야간투시, 무적급 회복 등) 원클릭 부여
  * 난이도 / 게임모드 체크마크 설정
  * 마인크래프트 명령어 직접 한 줄 실행
  * 서버 상태 / 실시간 CPU 및 메모리 부하 확인
  * 월드 백업 및 날짜별 이전 백업으로 원클릭 복구 (Restore)
  * 백업 파일 스마트폰 '내 파일' 또는 웹 브라우저(`http://IP:8080`)로 꺼내기
  * ⚠️ 월드 리셋 (기존 월드 자동 백업 후 새 맵 시작)
* **절전 방지 자동 적용:** 화면이 꺼져도 서버가 중단되지 않도록 `termux-wake-lock` 기본 적용
